# CIS 2348

University of Houston catalog title: Information Systems Application Development.

Python homework, ZyBooks labs, and the part 1 inventory final project. Every file in this folder was copied unchanged from [sydneyani/cis2348-sydney-ani](https://github.com/sydneyani/cis2348-sydney-ani) (`main`). That repository was not modified. Source commits are dated 17 June 2023 through 3 August 2023.

## What this folder contains

| Folder | Original folder | Contents |
| --- | --- | --- |
| [`zylabs-and-homework-problems`](zylabs-and-homework-problems) | `ZyLabs + Homework Problems` | Homework 1 (age from two dates) and early ZyLabs: integer math, a lemonade recipe scaler, wall paint, and an automotive service menu. |
| [`homework-2`](homework-2) | `Homework2` | Password strengthening, linear equations, coin change, a palindrome check, CSV word frequency, and date-parsing scripts (`CodingProblem2` and parts A–C). `README.txt` describes the first five problems. |
| [`homework-3`](homework-3) | `Homework3` | Classes for food calories, team win percentage, and a shopping cart, plus list filtering, word counts, and a jersey roster. |
| [`homework-4`](homework-4) | `Homework4` | Heart-rate calculation, age incrementing, a descending selection-sort trace, and quicksort with a call counter. `README.txt` describes each program. |
| [`final-project-part-1`](final-project-part-1) | `FinalProjectPart1` | An `Item` class and CSV readers that look up inventory by manufacturer and item type. `README.txt` describes the index, input, and output files. |
