# University Coursework

Coursework for Sydney Ani at the University of Houston, 2021–2025.

- **B.S. Computer Information Systems**
- **M.S. Engineering Data Science & AI**

Files are grouped by degree, then by course. Course codes come from the source repository and the assignment folders. This index does not record grades.

## Courses

| Course | Description | Folder |
| --- | --- | --- |
| CIS 2348 | Python homework, ZyBooks labs, and a CSV inventory final project for Information Systems Application Development. | [`bs-cis/cis2348`](bs-cis/cis2348) |

CIS 2348 is the catalog name [Information Systems Application Development](https://publications.uh.edu/preview_course_nopop.php?catoid=44&coid=210700). That title is the published course name for this code. It is not taken from a grade report.

No other course could be identified from the source repositories, so there is no `misc/` folder and no M.S. course folder.

## What each folder contains

### [`bs-cis/cis2348`](bs-cis/cis2348)

All of the CIS 2348 submissions from [sydneyani/cis2348-sydney-ani](https://github.com/sydneyani/cis2348-sydney-ani), kept in the original assignment groups:

- `zylabs-and-homework-problems` — Homework 1 and ZyLabs from the early chapters
- `homework-2` — ZyLabs 6–9 and date-parsing scripts
- `homework-3` — classes, lists, and dictionaries (ZyLabs 10–11)
- `homework-4` — exceptions and sorting (ZyLabs 12 and 14)
- `final-project-part-1` — CSV inventory lookup

The course README lists every file and the path it came from.

### M.S. Engineering Data Science & AI

No folder. Neither source repository contained files that could be identified as master's coursework, assignments, or labs.
